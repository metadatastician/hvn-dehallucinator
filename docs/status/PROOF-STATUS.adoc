= Proof status — hvn-dehallucinator
:revdate: 2026-10-14
:toc: preamble

Each row names the artefact that discharges it. Statuses are PROVEN (a checked
proof), TESTED (an executable check that can fail), ASSUMED, DESIGNED (a
written design, nothing executable) and OPEN (nothing yet). A status moves only
with a named module, lemma, fixture or log line. `scripts/check-proof-status.sh`
refuses this file if a row that is not OPEN names a path or a fragment that is
not in the tree.

== Where things stand

The engine's guarantee is *tested, not proved*. Four properties are each
checked by an executable suite that can fail: COMPLETE is written only from a
measured zero, a caller cannot assert progress, COMPLETE regresses, and the
attempt budget trips. That suite, and the witness suite below, run on every
pull request (Engine Guarantee workflow). When the engine regresses or refuses,
it now prints the blind-spot witness: the reading as recorded and the reading as
measured, and the claim they disagree on (HD-W). The 2026-08-23/24 Incident,
replayed at its literal numbers, is that block's test. What *is* proved is
the epistemic core of the guarantee, in the Agda kernel, against a model of the
engine's update (`verification/proofs/agda/Fibre.agda`, HD-F). The model shows
that the recorded state alone does not identify what remains, and that COMPLETE
needs an inhabited measured case. That model is not yet tied to `Engine.hs` by
any proof. The engine proofs recorded as done on 2026-08-27 are not in anything
pushed (see below). HDH-01 (#28) still adds the Haruspex design. The proof files
inherited from the template are not claims about this project; HDH-02 (#29)
tracks them.

specified the template's example request pipeline
(`idle → scanning → routing → dispatching`), not this engine, and no TLC gate
ever ran it. A TLA+ model of the engine belongs to HD-1.

`suc` monotonicity) was replaced by `Fibre.agda` on 2026-10-14. It imported
agda-stdlib, so it could not be checked under the kernel flags
(`--no-libraries`).
