= Proof status — hvn-dehallucinator
:revdate: 2026-10-26
:toc: preamble

Each row names the artefact that discharges it. Statuses are PROVEN (a checked
proof), TESTED (an executable check that can fail), ASSUMED, DESIGNED (a
written design, nothing executable) and OPEN (nothing yet). A status moves only
with a named module, lemma, fixture or log line. `scripts/check-proof-status.sh`
refuses this file if a row that is not OPEN names a path or a fragment that is
not in the tree.

== Where things stand

The engine's guarantee is *tested* against the engine itself and *proved*
against a model of it. Three suites run on every pull request (Engine Guarantee
workflow); each can fail and has been watched failing:

* the guarantee suite: COMPLETE only from a measured zero, no
  caller-asserted progress, regression, the attempt budget;
* the witness suite: the blind-spot witness on regress and refuse, with the
  2026-08-23/24 Incident replayed at its literal numbers;
* the hardening suite: root finding, parsing, verifier failures, pruning.

In the Agda kernel, `EngineCore.agda` models every command of `Engine.hs` and
proves THE GUARANTEE (no command introduces COMPLETE except an update whose
reading is a counted zero). It also proves the budget and completed-count
invariants and the breaker's behaviour. `Fibre.agda` proves the epistemic core:
the recorded state alone does not identify what remains, and COMPLETE needs an
inhabited measured case. A TLA+ model, checked by TLC, puts the engine against a
world that changes freely and a verifier that can fail. It finds no violation,
and it does find the Incident in the original engine. A differential test ties these models to
`Engine.hs` on 2,503 recorded engine traces (HD-F-E, TESTED; not a proof). The 2026-08-27 engine proofs were
never pushed; these re-derive them (see below). Haruspex, the same check run
before a prompt is sent, is
designed but not built (`docs/proposals/HARUSPEX.adoc`), and will live under
metadatastician. The proof files inherited from the template are not claims
about this project; HDH-02 (#29) tracks them.

== Engine proofs of 2026-08-27: absent, then re-derived

The 2026-08-27 work (`EngineCore.lean` with 19 theorems, `check-tla.sh`, 43/43
gate tests) was searched for on 2026-10-14 and is not in anything pushed:

* branches of `metadatastician/hvn-dehallucinator`: `main` only, plus the HDH-01 branches;

  `EngineCore.lean`, no `check-tla.sh`, no `.lean` file other than the template
  `ApiTypes.lean`, no `.tla` file other than the template `StateMachine.tla`,

  touched `*EngineCore*`, `*check-tla*` or `.handoff/`;

  (identical refs), not a separate copy.

The author's local clone was not reachable from the session that wrote this.

On the owner's decision (2026-10-14), HD-1 was re-derived from the engine
itself rather than recovered. If the original work later turns up, compare it
with the re-derivation; nothing here relies on it:

  Agda kernel because Lean is provenance only under the estate rulings. The

* `check-tla.sh` → `scripts/check-tla.sh` over
