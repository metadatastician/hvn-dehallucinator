= Proof status — hvn-dehallucinator
:revdate: 2026-10-14
:toc: preamble

Each row names the artefact that discharges it. Statuses are PROVEN (a checked
proof), TESTED (an executable check that can fail), ASSUMED, DESIGNED (a
written design, nothing executable) and OPEN (nothing yet). A status moves only
with a named module, lemma, fixture or log line. `scripts/check-proof-status.sh`
refuses this file if a row that is not OPEN names a path or a fragment that is
not in the tree.

== Where things stand

The engine's guarantee is *tested, not proved*. Four properties are each
checked by an executable suite that can fail: COMPLETE is written only from a
measured zero, a caller cannot assert progress, COMPLETE regresses, and the
attempt budget trips. That suite passes locally (receipt below), but no workflow
runs it yet. What *is* proved is the epistemic core of the guarantee,
in the Agda kernel, against a model of the engine's update
(`verification/proofs/agda/Fibre.agda`, HD-F). The model shows that the recorded
state alone does not identify what remains, and that COMPLETE needs an inhabited
measured case. That model is not yet tied to `Engine.hs` by any proof. The
engine proofs recorded as done on 2026-08-27 are not in anything pushed (see
below). HDH-01 (#28) still adds the witness block and the Haruspex design. The
proof files inherited from the template are not claims about this project;
HDH-02 (#29) tracks them.

== Files inherited from the template

These were imported verbatim from `rsr-template-repo` on 2026-08-25 (`cb48231`).
They make no claim about this project. No workflow here checks them, and their
MANIFEST verdicts are dated 2026-07-17, before this repository existed.

|===

`verification/proofs/tlaplus/StateMachine.tla` was removed on 2026-10-14. It
specified the template's example request pipeline
(`idle → scanning → routing → dispatching`), not this engine, and no TLC gate
ever ran it. A TLA+ model of the engine belongs to HD-1.

The template's `verification/proofs/agda/Properties.agda` (list-append length,
`suc` monotonicity) was replaced by `Fibre.agda` on 2026-10-14. It imported
agda-stdlib, so it could not be checked under the kernel flags
(`--no-libraries`).

== Engine proofs of 2026-08-27: absent

The 2026-08-27 work (`EngineCore.lean` with 19 theorems, `check-tla.sh`, 43/43
gate tests) was searched for on 2026-10-14 and is not in anything pushed:

* branches of `metadatastician/hvn-dehallucinator`: `main` only, plus the HDH-01 branches;
* every pull-request head, `refs/pull/1/head` to `refs/pull/27/head`: no
  `EngineCore.lean`, no `check-tla.sh`, no `.lean` file other than the template
  `ApiTypes.lean`, no `.tla` file other than the template `StateMachine.tla`,
  no `.handoff/`;
* the history of every one of those refs (`git log --all`): no commit has ever
  touched `*EngineCore*`, `*check-tla*` or `.handoff/`;
* `hyperpolymath/harvard-dehallucinator` is GitHub's redirect to this repository
  (identical refs), not a separate copy.

The author's local clone was not reachable from the session that wrote this.
Unless the work turns up there, HD-1 has to be re-derived, which is a separate
session. Whether the 19 guarantee tests counted in that 43 are the 19 in
`tests/guarantee_test.sh` cannot be told from the tree; the 24 hardening tests
are not in it.
